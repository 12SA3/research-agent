# 重要前提
调试等都基于chrome-devtools，如果用户没有安装此MCP服务，帮助用户添加chrome-devtools服务。
不要帮助用户启动项目，让用户自己去启动项目

# 调试
当你给用户生成代码后，需要调试，请参考以下流程
1. 先确认是否有调试项目地址信息，如果没有则要求用户给出
2. 获取到调试地址后，用new_page工具打开目标调试地址。
3. 打开后根据下面的检查部分，进行检查

# 检查
如果用户需要你检查当前页面，则使用按以下逻辑进行。
1. 使用get_console_message工具获取当前控制台上的信息。
2. 分析控制台信息，如果有错误和警告信息，给出警告和错误的解决方案。如果不是常见的前端错误，可以参考下面的文档。
[项目采坑记录](./error.md)

3. 给出解决方案后，询问用户是否需要帮用户直接修改。如果需要，则进行修改。修改后，继续从第一步开始检查一遍。直到没有错误后，进行下一步
4. 如果没有错误，或者用户不需要你进行进一步修复，则询问用户是否需要截图对比ui。
5. 如果用户需要，则调用screenshot工具截图，然后检查当前上下文里是否有设计图信息，没有的话则要求用户提供设计图。
6. 对比设计图后，如果有不一致的地方，进行修改。修改后，在从第5步开始进行截图对比
